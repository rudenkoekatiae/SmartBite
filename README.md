# SmartBite

SmartBite is a web application for personalized meal planning. It helps users create a balanced diet based on their individual goals, caloric needs, nutritional requirements, and budget.

The project was developed as a team educational project with a focus on UX design, MVP planning, and collaborative development.

---

## Project Overview

Many people face daily challenges related to nutrition:
- not knowing what to cook;
- eating monotonous meals;
- spending too much money on food;
- difficulty planning meals on a daily basis.

SmartBite addresses these issues by providing ready-made, personalized meal plans adapted to the user's needs and financial constraints.

## Features

- Personalized meal plan generation based on individual parameters  
  (user goals, calories, and nutritional values)
- Budget-aware meal planning
- Balanced nutrition with consideration of calories and nutrients
- Automatic generation of a shopping list based on the selected meal plan

## Target Audience

- People who want to:
  - lose weight
  - maintain weight
  - gain weight
  - Users who value:
  - time efficiency
  - budget control
  - structured and conscious eating

## User Interface

- Input form for personal parameters
- Goal selection
- Budget input
- Generated meal plan and shopping list output

## Technology Stack

- Frontend: HTML, CSS, TypeScript
- Backend: Python
- Tools: Git, GitHub
