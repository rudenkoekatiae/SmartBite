# SmartBite
Wb application that helps users plan their meals according to their nutritional goals (weight loss, maintenance, or weight gain) while staying within a defined budget.  The project is developed as part of an educational course and focuses on user-centered design, MVP planning, and collaborative software development.

  Run `npm run dev` to start the development server.
